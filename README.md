# ScuffedV4
Chat App, not supposed to be used in production, has many safety issues eg. exposed APIs endpoints.

## Installation
Clone the repository:

```bash
git clone https://github.com/n37a/silica
cd [REPOSITORY]
```
## Run
1. ```npm install ```
2. ```node server.js```
